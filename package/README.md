# DadsVeinmine

Whole-deposit vein mining built for Valheim 1.0.12.

Hold `Left Alt` while striking a mine rock or ore deposit with a valid pickaxe. Activation, progressive mining radius, section limits, per-frame processing, prefab exclusions, durability cost, stamina cost, and Pickaxes skill gain are configurable.

DadsVeinmine routes each section through Valheim's native mining handlers so normal tool-tier checks, network handling, effects, statistics, and item drops remain active.

Requires BepInEx only. Do not run another vein-mining plugin at the same time.
