# Changelog

## 1.0.0

- Added whole-deposit mining for Valheim `MineRock` deposits.
- Added whole-deposit mining for Valheim `MineRock5` deposits.
- Added hold-key, always-on, and off activation modes.
- Added progressive Pickaxes-skill radius.
- Added configurable per-frame processing.
- Added mandatory normal pickaxe durability decay for every mined section.
- Added processing termination when the active pickaxe reaches zero durability or is no longer equipped.
- Added native progressive section destruction and removal across the complete deposit.
- Added configurable stamina and Pickaxes skill costs.
- Added prefab exclusions.
- Added Thunderstore package support and original artwork.
