# Changelog

## 1.0.0

- Added whole-deposit mining for Valheim `MineRock` deposits.
- Added whole-deposit mining for Valheim `MineRock5` deposits.
- Added hold-key, always-on, and off activation modes.
- Added progressive Pickaxes-skill radius.
- Added configurable section and frame limits.
- Added configurable durability, stamina, and Pickaxes skill costs.
- Added prefab exclusions.
- Added Thunderstore package support and original artwork.
